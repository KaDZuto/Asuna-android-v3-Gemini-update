# Asuna VectorHeart — Android Version (AIgametest)
### Полное руководство по настройке, локальным моделям и провайдерам

Проект расположен в папке `AIgametest` — это самая новая и актуальная рабочая версия мобильного компаньона для Android 14 (Kotlin, Jetpack Compose, Live2D Cubism 2, Material 3).

## 📌 Что было исправлено и улучшено

### 1. Подключение к ИИ-провайдерам (Исправлено)
- **Разрешён Cleartext HTTP (`android:usesCleartextTraffic="true"`):** теперь Android не блокирует локальные сервера (Ollama, Termux `127.0.0.1:8080`, LM Studio и локальные TTS).
- **Безопасный парсинг JSON:** устранены падения при получении мультимодальных ответов (массивы parts), пустых полей `content` и мыслей модели (`reasoning_content` в DeepSeek-R1 / Gemini Flash Thinking).
- **Информативные ошибки:** вместо загадочного `no choices в ответе` приложение теперь выводит точный текст ошибки от провайдера (неверный ключ, лимиты, отсутствие баланса).
- **Исправлен Gemini API:** убран конфликт префиксов `models/`, установлен современный дефолт `gemini-3.8-flash` (вместо несуществующего на endpoint `gemma-3-27b-it`), добавлена фильтрация технических токенов мыслей.
- **Поддержка DeepSeek:** добавлены пресеты для официального API DeepSeek (`https://api.deepseek.com/v1`, модели `deepseek-chat` и `deepseek-reasoner`).
- **Заголовки для OpenRouter:** добавлены обязательные заголовки `HTTP-Referer`, `X-Title` и `User-Agent`.

### 2. Функции из ПК-версии (`hermes_paperclip_agent`), перенесённые в Android
- **Система инструментов (Tool Calling Loop):**
  - Асуна умеет вызывать инструменты тегом `<tool>{"name":"...","args":{...}}</tool>`.
  - Приложение автоматически исполняет инструмент и возвращает результат модели для озвучки и реакции Live2D:
    - `calendar_add` — добавление событий в локальный календарь.
    - `calendar_list` — просмотр ближайших событий и заметок.
    - `calendar_remove` — удаление событий.
    - `web_search` — живой веб-поиск через DuckDuckGo (работает прямо из коробки без платных API-ключей!).
    - `device_status` — опрос состояния смартфона (модель Xiaomi Mi 11T, заряд батареи, время).
- **Долгосрочная память ("Режим сна"):**
  - Кнопка **😴 Режим сна** в окне чата: Асуна анализирует прошедший диалог, составляет краткое саммари и сохраняет его в `vectorheart_memory.json`.
  - Выжимки прошлых разговоров автоматически подмешиваются в системный промпт при следующих запусках.
- **Тренажёр знакомств (Пикап-режим):**
  - Кнопка с сердцем в нижней панели переключает Асуну в режим тренировки знакомств.
  - Генерируются случайные локации (в кофейне, в метро, на выставке), ситуации, настроение и характер незнакомки (закрытая, игривая, занятая, скептичная).
  - Никакой долгосрочной памяти в этом режиме — честная, реалистичная обратная связь на подход пользователя.
- **Точное системное время:** дата и время на русском языке автоматически передаются в промпт модели.

### 3. Исправление синтеза речи (TTS)
- **Фильтрация тегов:** перед озвучкой из текста вырезаются теги `<live2d>`, `<tool>`, звездочки действий (`*улыбнулась*`), markdown-разметка и ссылки.
- **Надёжная работа на Xiaomi HyperOS:**
  - Проверка наличия русской голосовой базы.
  - Если в системе не скачан русский голос Google Speech Services, добавлена кнопка перехода в системные настройки загрузки голосов (`ACTION_INSTALL_TTS_DATA`).
  - Управление аудиофокусом Android (`AudioFocusRequest`), предотвращающее глушение звука системой энергосбережения MIUI/HyperOS.
- **Живой анимированный липсинк:** рот аватара теперь плавно артикулирует в такт речи с синусоидальной модуляцией (вместо статичного застывания с открытым ртом).
- **Поддержка сетевого Silero TTS:**
  - В настройках можно переключить TTS с системного Android на HTTP-сервер Silero TTS (голос `baya`) из ПК-версии (`server/tts_server.py`).
  - При недоступности сервера происходит мягкий авто-откат на системный TTS.

#### Запуск Silero TTS сервера (ПК)
1. Установите зависимости: `pip install torch` (и Python 3.10+).
2. Запустите:
   ```bash
   python3 server/tts_server.py --host 0.0.0.0 --port 8000
   ```
3. Проверка: `curl "http://127.0.0.1:8000/health"` и `curl "http://127.0.0.1:8000/?text=привет&speaker=baya" -o out.wav`.
4. В приложении Asuna: TTS → Сетевой Silero, URL `http://<IP_ПК>:8000/`.
5. Если `torch`/silero не установлены, сервер отвечает понятной ошибкой `503` вместо падения; `/health` тогда вернёт `503`.

## 📱 Локальные ИИ модели (Офлайн) на Xiaomi Mi 11T (Android 14)

Смартфон **Xiaomi Mi 11T** оснащён процессором **MediaTek Dimensity 1200 Ultra** и **8 ГБ оперативной памяти**.
На этом чипе локальные модели работают очень быстро при правильной настройке:

### Рекомендованные модели (.gguf):
1. **Qwen 2.5 1.5B Instruct (Q4_K_M)** — ~1.05 ГБ. Скорость: **26–32 токена/сек**. Идеально понимает русский язык и команды персонажа.
2. **Llama 3.2 1B Instruct (Q4_K_M)** — ~780 МБ. Скорость: **35–42 токена/сек**. Минимальный нагрев и расход батареи.
3. **Llama 3.2 3B Instruct (Q4_K_M)** — ~2.02 ГБ. Скорость: **16–20 токенов/сек**. Отличный интеллект при потреблении ~2.7 ГБ ОЗУ.
4. **Gemma 2 2B IT (Q4_K_M)** — ~1.65 ГБ. Скорость: **19–24 токена/сек**.

### Запуск через Termux на телефоне:
1. Установите **Termux** (из F-Droid).
2. Выполните установку `llama.cpp`:
   ```bash
   pkg update -y && pkg install clang cmake git -y
   git clone https://github.com/ggerganov/llama.cpp && cd llama.cpp
   cmake -B build -DLLAMA_OPENMP=ON && cmake --build build --config Release -j4
   termux-setup-storage
   ```
3. Скачайте модель (например, `qwen2.5-1.5b-instruct-q4_k_m.gguf` с HuggingFace) в папку `Загрузки`.
4. Запустите сервер (команда оптимизирована под 4 ядра Cortex-A78):
   ```bash
   ./build/bin/llama-server -m ~/storage/downloads/qwen2.5-1.5b-instruct-q4_k_m.gguf -c 2048 -t 4 --port 8080 --host 127.0.0.1
   ```
5. В приложении Асуны: кнопка **Локальные модели (чип памяти)** → **Подключить к Асуне** (адрес `http://127.0.0.1:8080/v1`).

## ⚡ Подключение подписки Gemini AI Pro / Antigravity CLI (Без нарушения ToS)

Вы можете использовать квоты вашей подписки **Google One AI Premium / Gemini AI Pro** двумя официальными путями:

### Способ 1: Бесплатный/Pro API-ключ в Google AI Studio (Рекомендуется)
1. Перейдите на официальный портал разработчиков Google: [aistudio.google.com](https://aistudio.google.com/).
2. Авторизуйтесь под вашим Google-аккаунтом с подпиской.
3. Нажмите **Get API Key** и скопируйте ключ.
4. В приложении Asuna:
   - Провайдер: **Gemini Pro / AI Studio**
   - Модель: `gemini-3.8-flash` (актуальный дефолт, `gemini-2.0-flash` отключён Google 2026-06-01)
   - Вставьте ключ.
5. Это полностью официально, стабильно и даёт до 15 запросов в минуту бесплатно или по вашей квоте.

### Способ 2: Локальный мост Antigravity CLI (`antigravity_bridge.py`)
Если на вашем ПК уже настроен и авторизован `agy` (Antigravity CLI):
1. Запустите скрипт моста на ПК:
   ```bash
   python3 server/antigravity_bridge.py --port 8080 --host 0.0.0.0 --token <ваш_токен>
   ```
   По умолчанию мост слушает `127.0.0.1`; `--host 0.0.0.0` открывает доступ из Wi-Fi — всегда задавайте `--token`.
2. Мост запустит локальный HTTP-сервер, который принимает стандартные OpenAI-запросы от телефона и вызывает команду `agy -p` под вашей авторизованной учётной записью Google.
3. В приложении Asuna на телефоне (в той же Wi-Fi сети):
   - Провайдер: **Antigravity CLI (ПК)**
   - Base URL: `http://<IP_ПК>:8080/v1`
   - Модель: `gemini-3.8-flash-high` или `gemini-3.1-pro-high`
4. Никакого парсинга cookie или взлома сессий — используется официальный CLI Google Antigravity!
