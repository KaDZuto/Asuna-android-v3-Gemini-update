Анимации
LLM / Гемма (текст + голос)
Обязательно с http:// в начале. Для локальной Ollama (OpenAI-совместимый режим) — полный адрес вместе с путём: http://127.0.0.1:11434/v1/chat/completions. Поле «Адрес Ollama» ниже — только для автозапуска, для самого чата используется это поле.
Голос (Silero TTS, voice: baya)
Чем меньше «пауза для конца фразы» — тем быстрее Асуна отвечает, но выше риск, что она перебьёт тебя на естественной паузе в речи. 700-1000мс обычно комфортно.
Экспериментально: пока она говорит, VAD слушает с повышенным порогом и, если ты заговоришь достаточно уверенно, сразу обрывает её ответ и начинает записывать тебя. Микрофон без аппаратного эхоподавления может иногда путать её же голос из динамиков со своим — если ловишь ложные срабатывания, выключи и слушай в наушниках.

Контент и поведение
В раскрепощённом режиме Асуна становится более эмоциональной и откровенной.
Живость (small talk)
Асуна изредка заговаривает сама — случайная мысль, вопрос, шутка — без всякого повода с твоей стороны. Откладывается, если вы уже активно общаетесь.
Google Calendar
Не подключён — используется локальный календарь.
Нужны свои OAuth-креденшлы (бесплатно, 5 минут): создай проект в Google Cloud Console, включи Google Calendar API, создай OAuth Client ID типа «Desktop app» и вставь Client ID/Secret сюда.

Режим наблюдения (скриншот раз в N сек)
Асуна будет видеть маленький снимок твоего экрана и изредка комментировать, если там что-то интересное. Ничего не сохраняется на диск. Выключено по умолчанию.
Ollama (локальная Gemma)
Приложение само пытается поднять "ollama serve" и прогреть модель при запуске — руками ничего включать не нужно, если Ollama установлена и есть в PATH.

Режим отработки знакомств
Отдельный, полностью изолированный режим-тренажёр: случайное место, случайная ситуация, случайный характер — цель научиться начинать разговор с незнакомым человеком. Ничего из этого режима НЕ сохраняется в долгосрочную память и не смешивается с обычным чатом. Персонаж всегда реагирует реалистично, а не автоматически благосклонно.
