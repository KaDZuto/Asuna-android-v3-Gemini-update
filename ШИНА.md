### Скачивание моделей прямо из приложения (как в AI Edge Gallery)
- `LocalModelManager.downloadModel()`: OkHttp + прогресс (1% c throttling в Main), **докачка через Range** (`.part` файл), токен HuggingFace (`Authorization: Bearer`), понятные ошибки 401/403, проверка свободного места (`StatFs`), регистрация в `asuna_local_models.json`, авто-подключение модели к Асуне после скачивания.
- Проверенные ссылки HuggingFace (сверены с HF API, размеры реальные):
  - Qwen 2.5 1.5B Instruct q8 ekv4096 — `.task`, 1.60 ГБ — основной выбор, длинный контекст, Apache-2.0, без логина
  - Qwen 2.5 1.5B Instruct q8 ekv1280 — `.task`, 1.60 ГБ — быстрее, экономнее по RAM
  - Qwen 2.5 0.5B Instruct q8 — `.task`, 0.55 ГБ — самая лёгкая/быстрая
  - Phi-4-mini-instruct q8 ekv4096 — `.task`, 3.91 ГБ — умнее, нужно 4+ ГБ RAM
  - Gemma 3 1B-it int4 — `.task`, 0.56 ГБ — **gated**, нужен токен HF
  - Gemma 3n E2B — прямой ссылки нет, открыть в AI Edge Gallery
- UI: секция «Скачать модель прямо из приложения», прогресс-бар, «Свободно на телефоне», поле токена HF + «Как получить», бейдж «Уже скачано».

### On-device инференс переписан на сессии (как в галерее)
- `OnDeviceLlmEngine`: `LlmInferenceSession` вместо плоского промпта — движок сам держит KV-кэш истории; системный промпт (личность+память) уходит **один раз** за диалог; `resetConversation()` при смене модели/провайдера; потоковая выдача через `generateResponseAsync(ProgressListener)` с мостом Guava `ListenableFuture → suspendCancellableCoroutine`; `cancel()`; `sizeInTokens` для расчёта контекста.
- `LlmRepository`: `onPartial`-стриминг, on-device суммаризация («режим сна» больше не уходит в облако), `onDeviceContextLimit()` по размеру системного промпта.
- `MemoryManager`: `saveSummaryRaw()` и `summarizeLocally()` (автономный фолбэк, если on-device модель не загрузилась).
- `ChatScreen`: живой текст ответа во время генерации, сброс диалога при смене провайдера/модели.
